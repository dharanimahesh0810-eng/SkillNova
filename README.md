# 🎓 AI-Powered Personalized Learning & Career Guidance Platform

📌 Overview

This project implements **SkillNova**, an AI-powered personalized learning and career guidance platform that helps students identify skill gaps, receive customized learning recommendations, and explore suitable career paths. The system combines Artificial Intelligence, personalized assessments, and educational datasets to create an adaptive learning experience for every student.


 🚀 Features

1. Student Profile Management with educational details, skills, interests, and career goals.

2. AI-powered Skill Assessment to evaluate current knowledge and identify strengths and weaknesses.

3. AI Skill Gap Analysis to determine missing skills required for the selected career path.

4. Personalized Learning Roadmap generated based on assessment results and career goals.

5. Intelligent Course Recommendation System suggesting relevant learning resources.

6. Progress Tracking Dashboard to monitor completed milestones and learning performance.

7. AI Chat Assistant for doubt clarification and personalized learning support.

8. Career Guidance Module recommending suitable career paths based on user skills and interests.
